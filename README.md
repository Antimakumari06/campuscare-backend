# CampusCare Backend ⚙️

A backend service built to power campus management systems — handling data, requests, and core logic for student and administrative operations, with data persistence using MongoDB.

## Features
- 🔧 RESTful API built with Express.js for handling campus-related data and operations
- 🗄️ MongoDB database integration for storing and managing data
- 🔐 Organized routes and controllers for scalability
- 📡 Designed to integrate smoothly with frontend applications

## Tech Stack
- **Backend Framework:** Node.js, Express.js
- **Database:** MongoDB

## How to Run
1. Clone the repository: `git clone https://github.com/Antimakumari06/campuscare-backend.git`
2. Navigate into the project folder: `cd campuscare-backend`
3. Install dependencies: `npm install`
4. Create a `.env` file in the root folder and add your MongoDB connection string: `MONGO_URI=your_mongodb_connection_string`
5. Start the server: `npm start`
